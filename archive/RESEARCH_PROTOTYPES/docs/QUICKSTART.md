# Differential KV Quickstart

## 1. Installation
```bash
pip install -e .[gpu]
```

## 2. Diagnostics
Check your environment:
```bash
dkv doctor
```

## 3. Launch Server
```bash
dkv serve --model Qwen/Qwen2.5-7B-Instruct
```

## 4. Run Examples
Check the `examples/` directory for integrations with LangChain, LlamaIndex, and more.
