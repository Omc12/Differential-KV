\section{Reproducibility}
\label{app:repro}

All results were produced on a single machine, one engine per isolated subprocess, with every
number measured (failed cells are reported as failures, never filled with estimates).

\paragraph{Hardware.}
Apple~M3, $8.6$\,GB unified memory, macOS (Darwin~25.x). The device is shared with the OS and
other applications, so absolute memory thresholds and long-context prefill times shift with
machine load; the scaling slopes, engine ordering, and exact-recall results are the stable
outcomes.

\begin{sloppypar}
\paragraph{Software.}
Python in \texttt{diffkv\_venv}, MLX~$0.31.2$, \texttt{mlx\_lm}, NumPy~$2.x$,
PyTorch (used only for tensor plumbing in the wrapper, not for compute),
\texttt{psutil}. Model: \path{mlx-community/Qwen2.5-1.5B-Instruct-4bit}
(group size $64$, $4$-bit), $28$ layers, $12$ query heads, $2$ KV heads, head
dim $128$, trained context $32{,}768$, RoPE $\theta=10^6$.
\end{sloppypar}

\begin{sloppypar}
\paragraph{Configuration (as measured).}
preset \texttt{mid}, \texttt{serving\_mode=balanced}, \texttt{rank=32} (the ``mid'' preset
default; only the ``low'' preset reduces it to $16$), \texttt{block\_size=256},
\texttt{recency\_window=512} (dense buffer~$768$), \texttt{max\_blocks=256},
\texttt{max\_residual=128}, top-$K{=}16$ routing with the \texttt{residual} router,
\texttt{DIFFKV\_SVD\_SEED=1234} (deterministic). The \diffkv{} engine runs in
the active CLI's serving configuration with the sparse path forced on at every
context: \texttt{DIFFKV\_COMPRESSED\_DECODE=1} (so DiffKV's compressed decode is
what is measured at all lengths, not the adaptive dense-below-threshold policy),
\texttt{DIFFKV\_DECODE\_CACHE=1} (decompress-and-cache; bit-exact),
\texttt{DIFFKV\_SPARSE\_PREFILL=1} (block-sparse prefill),
\texttt{DIFFKV\_SPARSE\_BIAS=auto} (adaptive merge bias, as the CLI ships).
The dense baseline is \texttt{mlx\_lm} with a full KV cache on the same int4
weights. The residual sweep (E5) forces \texttt{DIFFKV\_COMPRESSED\_DECODE=1}
and varies \texttt{DIFFKV\_MAX\_RESIDUAL}; the decode-mode ablation (E6) toggles
\texttt{DIFFKV\_COMPRESSED\_DECODE} between $1$ (compressed) and $0$ (exact
upper bound) over the same store.
\end{sloppypar}

\paragraph{Protocol.}
A needle-in-a-haystack chat prompt is built once per context length from the Qwen2.5 tokenizer and
fed verbatim (raw mode, no double chat-templating) to every configuration. The needle is a planted
passcode (\texttt{OMEGA-7741-DELTA}); ``needle recovered'' means the generation reproduced it.
Engines are warmed once (a $1$-token forward to compile kernels) before timing. Prefill is timed
with \texttt{perf\_counter} around the chunked forward after \texttt{mx.eval}; decode is
fixed-length greedy ($128$ tokens, EOS ignored) so throughput is directly comparable. Memory is
read from MLX's allocator (\texttt{get\_peak\_memory}). Each \texttt{(engine, context)} cell runs
in its own subprocess so memory is attributable and an out-of-memory event kills only that cell.
The full primary sweep is a single back-to-back batch, so \diffkv{} and dense are measured under
the same machine conditions; the volatile long-context dense cells were re-measured in isolation to
confirm their regime.

\paragraph{Commands.}
\begin{quote}\small\ttfamily
\# fresh primary sweep (active vs dense, 4k--32k), isolated per cell\\
CTXS="4096 8192 16384 32768" bash paper/scripts/measure\_sweep.sh\\[3pt]
\# 64k reach point + long-context dense re-check\\
bash paper/scripts/measure\_tail.sh\\[3pt]
\# decode-mode ablation (compressed vs exact, same store)\\
DIFFKV\_DECODE\_CACHE=1 diffkv\_venv/bin/python3 paper/scripts/measure\_active.py \textbackslash\\
\ \ --ctx 4096 8192 16384 32768 --modes compressed exact --gen 128 \textbackslash\\
\ \ --out paper/generated/active\_modes\_fresh.json\\[3pt]
\# residual-budget sweep at 16k\\
diffkv\_venv/bin/python3 paper/scripts/measure\_residual\_sweep.py \textbackslash\\
\ \ --ctx 16384 --residuals 0 8 16 32 64 128 \textbackslash\\
\ \ --out paper/generated/residual\_sweep\_fresh.json\\[3pt]
\# facts, figures, and tables from the measured JSON (no hand-typed numbers)\\
diffkv\_venv/bin/python3 paper/scripts/make\_facts.py\\
diffkv\_venv/bin/python3 paper/scripts/make\_diagrams.py\\
diffkv\_venv/bin/python3 paper/scripts/make\_graphs.py\\

\end{quote}

\paragraph{Artifacts and provenance.}
Primary measured JSON: \path{benchmarks/results/fresh_{active,dense}_{ctx}.json}.
Ablations: \path{paper/generated/active_modes_fresh.json} (decode modes) and
\path{paper/generated/residual_sweep_fresh.json} (residual budget). Every figure
and table is regenerated from these by the scripts above; the body text's numbers
