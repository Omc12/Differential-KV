\section{Fused Routed Decode Attention}
\label{sec:decode}

\begin{\figenv}[t]
  \centering
  \includegraphics[width=\linewidth]{figures/f5a_decode_attention.pdf}
  \caption{The routed sparse decode kernel. A cheap exact router keeps the top-\topk{} blocks. Their
  contribution is computed in the rank-\rank{} subspace---anchor score plus a projected-query dot
  with $U$---without ever forming $\hat K$. In parallel, the selected blocks' exact residuals and
  the dense recency window are attended directly. The two halves are combined by a flash-style
  log-sum-exp merge, guarded so an empty compressed set contributes exactly zero weight.}
  \label{fig:decode}
\end{\figenv}

Decode is where compression must pay off without materializing the cache. The decode kernel
(Figure~\ref{fig:decode}) computes, for a single query $q\in\R^{\Hq\times\dhead}$, an
attention output over the compressed pool and the dense window as two halves merged in log-space.
\S\ref{sec:fusedbuf} then shows how the runtime amortizes that computation across tokens.

\subsection{Routing: bound the work, not the context}
Attending and reconstructing every block would make decode scale with context. Instead a router
scores all blocks cheaply and keeps the top $\topk{=}16$. The default router is \emph{exact}: it
scores $q$ against each block's anchor key and its most distinctive residual keys, and ranks blocks
by the largest true dot product,
\begin{equation}
  \rho_b \;=\; \max\!\Big(\, q\cdot \anchork^{(b)},\ \max_{j\le \maxres} q\cdot R^{(b)}_{K,j} \,\Big)\cdot \text{scale}.
  \label{eq:router}
\end{equation}
Because the residuals \emph{are} the block's outlier tokens, scoring them gives a tight relevance
signal that reliably keeps a needle's block in the top-\topk{} even at large block counts---where a
min/max box bound (also available, and cheaper, in the style of Quest~\cite{tang2024quest}) becomes
too loose. Routing costs $O(\text{nb}\cdot
\maxres\cdot\dhead)$ per token and is the dominant decode cost at long context, so the number of
residuals \emph{scored} by the router is decoupled from the number \emph{stored}
(\S\ref{sec:impl}).

\subsection{Sparse half: scoring in the low-rank subspace}
For each selected block the kernel scores $q$ against every token \emph{without reconstructing
$K$}. Using Eq.~\eqref{eq:recon}, the score of token $i$ decomposes into an anchor term and a
delta term:
\begin{equation}
  q\cdot \hat K_i \;=\; \underbrace{q\cdot \anchork}_{\text{anchor score}}
  \;+\; s\,\big(\underbrace{q\, V_K^{\!\top}}_{\tilde q\,\in\,\R^{\rank}}\big)\cdot U_i .
  \label{eq:lowrankscore}
\end{equation}
The query is projected once into the rank-\rank{} subspace ($\tilde q = q V_K^{\!\top}$), and all
$\bs{-}1$ token scores in a block are then a single $\tilde q\,U^{\!\top}$ product. This is
$O(\topk(\Hkv \rank\dhead + \rank \bs))$ per token---linear in the rank and independent of $\dhead$
in the inner loop---rather than the $O(\topk\,\bs\,\dhead)$ of decompress-then-score. The value
side is symmetric: softmax weights are contracted with $U$ and then with $V_V$, plus the anchor
contribution, giving the sparse output $O_{\text{sp}}$ and its log-sum-exp $\lse_{\text{sp}}$.
Residual positions are masked out of this pool so their exact copies (below) are their sole
representation.

\subsection{Exact half: residuals and recency}
The selected blocks' exact residual keys/values are concatenated with the dense recency window and
attended directly in fp16---an ordinary masked attention producing $O_{\text{dn}}$ and
$\lse_{\text{dn}}$. This half is where a buried passcode is recovered verbatim: its token, being a
high-error outlier, was kept exact as a residual, so the query attends to the true key and copies
the true value.

\subsection{Flash-style merge}
The two halves are combined by the standard online-softmax identity used by
FlashAttention~\cite{dao2022flashattention}, in a numerically guarded form:
\begin{equation}
  m = \max(\lse_{\text{sp}}, \lse_{\text{dn}}),\quad
  o = \frac{e^{\lse_{\text{sp}}-m}\,O_{\text{sp}} + e^{\lse_{\text{dn}}-m}\,O_{\text{dn}}}
           {e^{\lse_{\text{sp}}-m} + e^{\lse_{\text{dn}}-m}} .
  \label{eq:merge}
\end{equation}
NaN/inf guards make an empty compressed set contribute exactly zero weight, so the kernel degrades
to pure dense-window attention with no special case. We keep the score and combine arithmetic in
the precision the kernel was validated at (fp16 products with fp32 log-sum-exp accumulation);
recasting the merge to fp32 was measured to perturb long-context retrieval and is avoided
(\S\ref{sec:impl}). An optional additive bias on the compressed half's log-sum-exp corrects a
systematic under-weighting of the low-rank pool for diffuse multi-fact queries; it defaults to a
no-op and does not affect the exact single-needle recall reported here.

\subsection{Fused decode buffer}
\label{sec:fusedbuf}

\begin{\figenv}[t]
  \centering
  \includegraphics[width=\linewidth]{figures/f5b_fused_buffer.pdf}
  \caption{The fused decode buffer. Every $N{=}16$ tokens the routed blocks' reconstructed rows,
  their exact residuals, and the dense recency window are written into one pre-allocated
  contiguous buffer. Grey cells score $-\infty$ under the fixed additive mask---the low-rank twins
  of the residual rows, and the unused tail---so each token is represented exactly once. Between
  rewrites, a step appends the new token's $K$/$V$ as a single in-place row and issues one
  \texttt{scaled\_dot\_product\_attention} over exact-length views. Attending the union of these
  rows in one softmax is algebraically the log-sum-exp merge of the two halves in
  Figure~\ref{fig:decode}.}
  \label{fig:fusedbuf}
\end{\figenv}

Reconstructing the routed blocks for every token is the dominant per-token cost. To amortize
it, the runtime uses a \emph{persistent fused buffer} (Figure~\ref{fig:fusedbuf}): at each routing interval (default
$N{=}16$ tokens), the selected blocks' $K$/$V$ are materialised into a contiguous static buffer
---one row per non-masked token---together with their exact residuals and the dense recency
window, guarded by a fixed additive mask that gives residual positions infinite score and zeroes
out the low-rank twins of residual rows so each token is represented once. Per-token decode then
appends the new token's $K$/$V$ as a single in-place row and runs one
\texttt{scaled\_dot\_product\_attention} call over exact-length views, without any per-token
concatenation or buffer re-allocation. The block set is re-routed and the buffer re-written
every $N$ tokens (or when the set changes). This path (\texttt{DIFFKV\_DECODE\_FUSED},
default on) is bit-exact to the per-token sparse kernel; its effect on throughput is part of
the measured decode numbers in \S\ref{sec:eval}.

\begin{\algenv}[t]
\caption{Fused routed decode attention for query $q$ (one layer)}
\label{alg:decode}
\begin{algorithmic}[1]
\Require query $q$; pool $\{U,V_K,V_V,\anchork,\anchorv,s,R_K,R_V\}_{b}$; dense window $K_d,V_d$
\State $\rho_b \gets \max(q\cdot\anchork^{(b)}, \max_j q\cdot R^{(b)}_{K,j})\cdot\text{scale}$ \Comment{Eq.~\eqref{eq:router}}
\State $\mathcal S \gets$ top-\topk{} blocks by $\rho_b$
\For{$b\in\mathcal S$}                                  \Comment{scored in rank space, no $\hat K$}
  \State $\tilde q \gets q\,V_K^{(b)\top}$;\quad scores$_i \gets q\cdot\anchork^{(b)} + s\,\tilde q\cdot U^{(b)}_i$
  \State mask residual positions to $-\infty$
\EndFor
\State $O_{\text{sp}},\lse_{\text{sp}} \gets$ softmax/combine over pooled block scores with $V$ side of Eq.~\eqref{eq:recon}
\State $O_{\text{dn}},\lse_{\text{dn}} \gets$ exact attention over $[\,R_{K,\mathcal S}\,\|\,K_d\,],[\,R_{V,\mathcal S}\,\|\,V_d\,]$
\State \Return flash-merge$(O_{\text{sp}},\lse_{\text{sp}},O_{\text{dn}},\lse_{\text{dn}})$ \Comment{Eq.~\eqref{eq:merge}}
\end{algorithmic}
\end{\algenv}
